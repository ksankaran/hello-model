# Hello, Model!

Build your first AI model from scratch in pure Python. No frameworks, no magic - just gradient descent and houses.

## Notebooks

### 1. Hello, Model!

Your first model: `y = mx + b`, 2 parameters, 7 houses.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ksankaran/hello-model/blob/main/hello_model.ipynb)

- What a model actually is (a function with knobs)
- How to measure "wrongness" with a loss function
- How gradient descent turns the knobs automatically
- How to train a model and predict on new data

[Blog post](https://medium.com/@v31u/hello-model-build-your-first-ai-model-from-scratch-552ecdffdfe9)

### 2. From Line to Network

Your first neural network: 3 neurons, 10 parameters, 10 houses.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ksankaran/hello-model/blob/main/neural_network.ipynb)

- Why a straight line fails on curved data
- What a neuron is (a line with a bend - ReLU)
- How stacking neurons creates a neural network
- Backpropagation explained step by step
- Same training loop, just more knobs

## No Dependencies

Both notebooks use pure Python. No numpy, no sklearn, no pytorch. Just `import random`.
